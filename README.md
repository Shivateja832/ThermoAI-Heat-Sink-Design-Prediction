# ThermoAI Heat-Sink Design Explorer

A Streamlit application for exploring the supplied steady-state heat-sink calculation and comparing its results with Random Forest and Extra Trees surrogate models.

## Features

- Calculate total thermal resistance and junction temperature for an operating point.
- Compare the engineering calculation with either surrogate model.
- Review holdout MAE, RMSE, and R² results.
- Compare the Random Forest and Extra Trees holdout scores (MAE, RMSE, and R²) in the Model Validation tab; the results are also saved in `surrogate_metrics.csv`.
- Inspect Pearson/Spearman sensitivity and download the generated sweep CSV and summary report.

## Run Locally

```powershell
python -m pip install -r requirements.txt
python Heat_Sink_calculation.py
python -m streamlit run app.py
```

Streamlit opens the application at `http://localhost:8501`.

## Dataset and Scope

`heat_sink_sweep.csv` contains 6,000 deterministic cases from the supplied calculation: 20 TDP levels from 30–250 W, 25 air-velocity levels from 0.5–15 m/s, and 12 TIM-conductivity levels from 1–12 W/m·K. The targets are generated by the calculation; they are not measured experimental data. The surrogate is intended for interpolation within these ranges and does not replace engineering validation.

Run `python Heat_Sink_calculation.py` to regenerate the dataset, model metrics, and sensitivity CSVs.
